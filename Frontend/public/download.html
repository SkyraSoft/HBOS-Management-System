⚡ Installation & Setup Instructions

  • Windows Installation: Download HBOS_POS_1.0.0_STAGE3_UAT_x64_en-US.msi and run the installer. Standard per-user and per-machine installations are fully supported.
  • Window Trapping Remediation: The UAT build runs in a standard windowed frame (1366×768 resizable) with minimize/maximize/close controls, eliminating previous kiosk screen trapping.
  • Offline Demo Walkthrough: On startup, select “Explore Demo Mode” to execute full end-to-end retail scenarios locally without connecting to backend databases.
  • Local-First Offline Resilience: The application runs locally using an IndexedDB transaction queue. Pending offline sales persist across application restarts and synchronize automatically when connectivity is established.
  • Printer Configuration: Access Settings > Receipts within the application to configure 80mm/58mm thermal roll printing or A4/A5 laser/inkjet invoices. Hardware drawer kick depends on printer-driver configuration.
