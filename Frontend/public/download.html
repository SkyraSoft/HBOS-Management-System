⚡ Quick Installation & Thermal Printer Setup Guide

  • Zero Barcode Requirement: Counter cashier operates 100% via Live 2-Letter Fuzzy Name Search, Visual Category Tabs, and Brand Filters.
  • Dual Printer Setup: Navigate to Settings > Printer Settings inside the app to toggle between 80mm ESC/POS Thermal Roll Receipts or Standard A4/A5 Laser/Inkjet Invoices.
  • Local Image Storage: Product thumbnails and store logos are stored directly on the local machine disk (Base64 IndexedDB), saving cloud bandwidth.
  • Mandatory Shift-Close Exit Guard: Before closing shift or shutting down, click Close Shift to execute automatic bulk sync to Hostinger cloud and print Z-Report.
